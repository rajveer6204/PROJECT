# 🛒 Amazon Clone Website

A frontend Amazon Clone project built using **HTML5 and CSS3**. This project recreates the look and feel of an e-commerce shopping homepage with a navigation bar, search section, product categories, promotional banners, and footer.

## 🌐 Live Demo

🔗 **[View Amazon Clone Website](https://amazon-clone-rajveer.onrender.com)**

## 📂 GitHub Repository

🔗 [View Source Code](https://github.com/rajveer6204/PROJECT/tree/main/Amazon)

## ✨ Features

- Amazon-inspired homepage design
- Navigation bar with logo and search section
- Product category sections
- Promotional hero banner
- Product image cards
- Footer section
- Responsive layout elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- Images and other frontend assets

## 🚀 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/rajveer6204/PROJECT.git
```

2. Open the project folder:

```bash
cd PROJECT/Amazon
```

3. Open `index.html` in your browser.
